unadmin [target]Revokes session admin powers from the target player.
sban [target]Session-bans the target player from the server.

kick [target]Kicks the target player from the server.

Host Standards
Dress Code

Presentation is part of the job. While hosting, you're expected to wear a realistic outfit and use a realistic avatar at all times. It's one of the first things civilians notice, and it sets the tone for how seriously the session gets taken.

Host Of The Month Reward

Reaching Host Of The Month comes with a real reward: whoever earns the title that month receives a Diamond Pass for the following month.

Host Vehicle

Your vehicle while hosting should be an undercover LEO vehicle in white, using the hex code #D0D0D0. A small clearcoat metallic flake finish is a nice touch, but it's optional. The color itself is the only hard requirement.

Staff Vehicle

If you're staff inside someone else's session, your vehicle should instead be an undercover LEO vehicle in black. A glossy metallic iridescent finish is optional here too, same as with the host vehicle.

Session Procedures
Session Cooldown

Give it 15 minutes between sessions. If you've just ended one and want to start another, that's the minimum wait before hosting again.

Early Access & Verification

FRP is not tolerated during early access, full stop. Keep all civilians at spawn until everyone's been verified. The one exception is during reinvites, where civilians are free to leave as soon as they've rejoined. Verification itself is done with the /whois command in the bot channels.

Numbering System

Follow the server numbering system: if Server B has a session running, Server A needs one running too.

Pointing To Formats

Announcements are for players who might not know the format. You're welcome to point people toward session formats whenever it's useful, and clicking it will take you straight there.

Ending A Session & Leakers

When a session ends, announce the FRP time and let every ongoing scene continue rather than cutting it short. If you spot a leaker, remove them with sban [user] in the Cmdr window.

Kicking Civilians

Civilians can only be kicked for violating RP guidelines, and no announcement is needed when it happens. If a kicked civilian asks why, explain it in Discord or point them to open a ticket. There's no obligation to justify it in the session itself.

Going AFK & Staff Presence

Going AFK is fine, just notify the other staff members in the Moderator chat first. Civilians don't need to know. Make sure at least one staff member is present in the session at all times, and regenerate the session code whenever it's warranted.

In-Game Announcements

In-game announcements are reserved for important information and for answering questions. Respond to chat questions with something like "!example" rather than a full announcement. Lighter engagement prompts are fair game too, things like "how was your day" or "cats or dogs" to get civilians talking.

Engagement Tips

A few tips for keeping the roleplay engaging: encourage civilians to open their shops, use special perms where it fits, and announce whenever FD, DOT, or LEO are active in the session. Larger set piece RPs such as drag races, rooftop derby, and hide and seek are reserved for the end of the session only.

Capacity & Reinvites
Regenerating The Code

Once a session reaches full capacity, or gets close, or has multiple leakers inside it, regenerate the code using the /regen command in the Discord server.

Creating Reinvites

Once the link's been regenerated and there's open space again, use the /reinvites command in the Discord server to create reinvites.

Announcing Reinvites

When those reinvites go out, make sure to announce the RP information in-game so anyone joining fresh is caught up.
